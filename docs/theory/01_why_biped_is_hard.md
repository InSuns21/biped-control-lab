# 01. なぜ二足立位は難しいのか

二足歩行を理解する最初のポイントは、**「立っている」は静止して見えても、制御なしでは不安定になりやすい**ということです。

## 1. 安定な平衡点と不安定な平衡点

ボールをお椀の底に置くと、少しずらしても元へ戻ろうとします。これは安定平衡です。

一方、棒を指先の上に立てると、少し傾いただけでさらに傾きます。直立した倒立振子は不安定平衡です。

二足立位では、人間やロボットの重心は足より高い位置にあります。したがって、単純化すると「足元を支点にした倒立振子」として見ることができます。

## 2. 静的安定の最初の条件

床との接触領域を上から見たとき、その凸包を**支持多角形**と呼びます。

静止していると仮定すれば、重心の鉛直投影が支持多角形の内側にあることが、倒れないための基本条件です。

ただしこれはあくまで静的な話です。歩行中には加速度があるので、重心位置だけでは十分ではありません。

## 3. なぜ「重心が内側なら安全」だけでは足りないか

歩行では、重心は加速・減速します。床反力の作用点がどこにあるか、回転モーメントがどう釣り合うかを見る必要があります。

そこで登場するのが **Zero Moment Point（ZMP）** です。

ざっくり言えば、床面上で「水平軸まわりの転倒モーメントが 0 になる点」を考えます。ZMP が支持領域の外へ出ると、足裏だけでは必要なモーメントを作れず、別の戦略が必要になります。

## 4. 人間やロボットは何をしているのか

立位・歩行の制御は、概念的には次のループです。

1. センサで姿勢・角速度・接触状態を測る
2. 現在の状態を推定する
3. 倒れそうか評価する
4. 足首・股関節・着地点を決める
5. モータへ指令する
6. 再び測る

これは典型的なフィードバック制御です。

## 5. 二足歩行が難しい本質

難しさは「脚が2本あるから」ではありません。主には次の点です。

- 直立状態が不安定系に近い
- 支持領域が狭い
- 歩くたび支持脚が切り替わる
- 接触が入ったり切れたりする
- 摩擦制約がある
- モータの出力には上限がある
- センサにはノイズと遅延がある
- 外乱に対して、姿勢修正だけでなく足を出す判断も必要

## 6. この教材での単純化

第1版では、まず以下を捨てます。

- 3次元運動
- 多関節全身モデル
- 足裏の細かな圧力分布
- 摩擦円錐
- センサノイズ
- 通信遅延

代わりに、倒立振子・支持多角形・LIPM を使います。

これは「現実を無視する」ためではなく、**制御の核を分離して見る**ためです。
