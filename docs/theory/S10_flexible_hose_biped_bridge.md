# 補講 S10 — 柔軟ホース境界制御から二足歩行へ

> **対象**: Side Lab X1 を触って、「暴れるホースを手元から抑える話が、なぜ二足歩行制御につながるのか」を整理したい読者。
>
> **前提**: 第03章の P / PD、第04章の状態空間、第05章の LQR。第06・07章は未読でもよい。
>
> **この補講のゴール**: 柔軟ホースの flutter、境界制御、状態フィードバックを、倒立振子・LQR・ZMP・LIPM と混同せずに比較し、「状態を観測し、実現可能な入力を通じて不安定な運動を抑える」という共通構造を説明できるようにする。

[Side Lab X1: Flexible Hose Control](../labs/x1-shower-tvc/) では、内部に水が流れる柔軟ホースを手元から操作します。

見た目はシャワーですが、教材上の役割はかなり重要です。倒立振子のような1自由度に近い系から、**多数の振動モードを持つ柔軟系**へ一度寄り道することで、

- P / PD が何を見ているか
- 状態フィードバックがなぜ効くことがあるか
- LQR が「強い入力」ではなく「状態の使い方」を設計していること
- 入力飽和や可制御性がなぜ重要か

を、二足歩行へ戻る前に体験できます。

## 1. Phase 0 と Phase 1 は何が違うのか

Phase 0 は、シャワーヘッドをほぼ単一剛体として扱う比較モデルです。

重心が支点より下にあり、粘性減衰もあれば、少し傾けても自然に戻りやすくなります。これは「末端の流水反力だけを入れた剛体近似では、蛇のような暴れ方を説明しにくい」ことを見るためのモデルです。

Phase 1 では、ホースを柔軟体として扱います。線形化した有限要素モデルでは概念的に

$$
M\ddot{q}
+
C(U)\dot{q}
+
K(U)q
=
f
$$

と書けます。

ここで

- $q$: ホースの変形を表す多数の自由度
- $M$: 構造と内部流体を含む質量行列
- $C(U)$: 流速 $U$ に依存する速度結合を含む行列
- $K(U)$: 曲げ剛性と流速二乗項を含む行列

です。

重要なのは、流量を増やすと単に「外力が強くなる」のではなく、**系そのものの固有モードと安定性が変わる**ことです。

## 2. flutter は「外から揺らされ続ける」のとは違う

線形状態方程式

$$
\dot{x}=Ax
$$

を考えると、固有値 $\lambda$ の実部が

$$
\operatorname{Re}(\lambda)<0
$$

なら、そのモードは減衰します。

一方、

$$
\operatorname{Re}(\lambda)>0
$$

のモードが現れると、微小な摂動でも時間とともに成長します。

Side Lab X1 の高流量側で見たいのは、この**自励的な成長**です。毎フレーム見た目用の正弦波を足しているのではありません。

これは第04章の「固有値が時間応答を決める」という話の、多自由度版です。

[第04章: 状態空間と状態フィードバック](04_state_space.md)

## 3. 手元を動かすことは、境界から系へ入力すること

Side Lab X1 では、ノズルを直接ジンバルしていません。

プレイヤーや制御器が操作するのは、ホース根元の

$$
q_b(t)
=
\begin{bmatrix}
y_{\mathrm{hand}}(t)\\
\theta_{\mathrm{hand}}(t)
\end{bmatrix}
$$

です。

自由自由度を $q_f$、境界自由度を $q_b$ として行列を分割すると、

$$
M_{ff}\ddot{q}_f
+
C_{ff}\dot{q}_f
+
K_{ff}q_f
=
f_f
-
M_{fb}\ddot{q}_b
-
C_{fb}\dot{q}_b
-
K_{fb}q_b
$$

と読めます。

つまり手元運動は、単に絵を動かしているのではなく、**境界条件を通じてホース全体の運動へ作用する入力**です。

この考え方は二足歩行でも重要です。二足歩行では床との接触が境界条件になり、床反力や接触位置の制約を通じて身体運動へ作用します。

ただし、ホースの手元境界と足裏接触は同じ物理現象ではありません。

## 4. P / PD は「少数の見える量」だけで抑える

H1-6 の P / PD は、主に

- tip 横変位
- tip 横速度
- tip 角度
- tip 角速度

だけを使います。

たとえば概念的に

$$
u_P=-K_pe
$$

$$
u_{PD}=-K_pe-K_d\dot{e}
$$

です。

これは第03章の倒立振子と同じ発想です。

[第03章: PID / PDフィードバック](03_pid_feedback.md)

ただし柔軟ホースには多数の内部モードがあります。

先端が一瞬静かでも、中間部に振動エネルギーが残っていることがあります。したがって tip だけを見る P / PD は、低次元の倒立振子より情報不足になりやすいわけです。

ここで「D を増やせば全部解決」とは限りません。観測していないモードには、そもそも十分な情報がありません。

## 5. 状態フィードバックは内部モードまで見る

H1-6 の full-state 制御では、rod の角度・角速度と hand actuator state をまとめて状態ベクトルにします。

平衡点そのものを安定化するときは概念的に

$
u=-Kx
$

です。

一方、Side Lab X1 のゲームでは照準のために hand target 自体が動きます。このとき単純に元の平衡点へ戻すのではなく、線形化した離散系

$
x_{k+1}=Ax_k+Bu_k+c
$

に対し、照準入力 $u_{\mathrm{ref}}$ と整合する定常参照

$
(I-A)x_{\mathrm{ss}}
=
Bu_{\mathrm{ref}}+c
$

を解き、

$
u
=
u_{\mathrm{ref}}
-
K(x-x_{\mathrm{ss}})
$

として追従します。

第04章の状態フィードバックと同じ骨格ですが、状態次元が大きく、さらに「どの状態を目標状態とみなすか」も重要になります。

ここで大切なのは、状態を増やしたから自動的に制御できるわけではないことです。

入力 $u$ がそのモードへ影響できるかは、可制御性で決まります。

Side Lab X1 では、実際の nonlinear one-step map を平衡点まわりで数値線形化し、可制御性を診断してから状態フィードバックへ進みます。

これは「モデルを行列にしたから何でもできる」という話ではありません。

## 6. LQR は強いアクチュエータではない

LQR は

$$
J
=
\sum_k
\left(
x_k^TQx_k
+
u_k^TRu_k
\right)
$$

を小さくするように、状態フィードバックゲイン $K$ を決めます。

[第05章: LQR](05_lqr.md)

Side Lab X1 では Human / P / PD / State FB / LQR が、すべて同じ

- hand target clamp
- 速度上限
- 加速度上限
- 難易度ごとの authority

を通ります。

したがって LQR が良い結果を出しても、

> LQR だけ特別に強いアクチュエータを使った

という比較にはしていません。

違いは主に、**どの状態をどの重みで入力へ戻すか**です。

moving bullseye では State FB / LQR に共通して短い参照先読みを使います。これはアクチュエータを強くするのではなく、既知の参照軌道に対するtracking lagを補う feedforward 側の処理です。

また LQR のゲインは平衡点近傍の線形化モデルに基づきます。大振幅・大きなモデル誤差まで無条件に最適という意味ではありません。

## 7. TVCとは何が同じで、何が違うか

Thrust Vector Control（TVC）は、ロケットなどで**推力ベクトルの向き**を変え、機体へ力とモーメントを与える制御です。

Flexible Hose Control の不安定化機構は TVC ではありません。

ホースでは、

- 柔軟体の曲げ
- 内部を移動する流体
- 流速依存の連成
- 境界運動

が主要な要素です。

共通しているのは物理現象そのものではなく、

> 現在状態を観測し、実現可能な入力方向と入力限界の中で運動を制御する

という制御問題の骨格です。

「水が出ているから TVC」と呼ぶと、最も面白い内部流体・柔軟体連成を落としてしまいます。

## 8. CoP / ZMPとも同じものではない

第06章では、足裏接触から作れる床反力レンチを考えます。

[第06章: 支持多角形とZMP](06_zmp_support_polygon.md)

ZMP / CoP は、足裏のどこに床反力が作用しているか、そしてその作用点が支持領域内に収まるかを扱う概念です。

Side Lab X1 の hand boundary input と ZMP は同じ量ではありません。

比較すると次のようになります。

| 系 | 主な状態 | 主な入力 | 入力の実現可能性を制限するもの |
| --- | --- | --- | --- |
| Flexible hose | rod 角度・角速度・hand state | hand 位置・角度 target | hand travel、速度・加速度、流量 |
| 倒立振子 | 角度・角速度 | 支点トルク | トルク上限 |
| LIPM | 重心位置・速度 | ZMP / CoP 位置 | 支持多角形 |
| 実機二足 | 全身姿勢・速度・接触状態 | 関節トルク・接触力 | 摩擦、CoP、トルク、接触切替 |

共通しているのは、**制御器が欲しい入力を無制限に出せるわけではない**ことです。

## 9. LIPM / Capture Pointとの接続

第07章の LIPM は

$$
\ddot{x}
=
\frac{g}{h}(x-p)
$$

です。

ここでは $p$ が ZMP 位置です。

状態を分解すると、Capture Point / DCM に対応する発散成分が現れます。

[第07章: LIPMとステップ制御](07_lipm_step_control.md)

Flexible hose では発散し得るものが1個とは限らず、複数の柔軟モードを持ちます。

それでも見方は似ています。

- どのモードが増えているか
- そのモードへ入力が届くか
- 入力制約内で成長率を負へ戻せるか

を考えます。

LIPM では支持点 $p$ の可動範囲を使い、それでも足りなければステップして支持領域そのものを移します。

Flexible hose では hand boundary を動かします。

どちらも「不安定な状態に対して、実現可能な入力をどこまで使えるか」という問題です。

## 10. Side Lab X1で確認する実験

[Side Lab X1](../labs/x1-shower-tvc/) で同じ difficulty を選び、Control mode だけを変えてください。

特に見るべきなのは score の順位ではなく、

1. P と PD で tip の振動がどう変わるか
2. PD が速度情報を使うことで何を抑えているか
3. 高流量で local sensing だけでは何が残るか
4. State FB / LQR で moving hand frame に対する flexible RMS がどう変わるか
5. actuator saturation が出ていないのに結果が変わるか
6. Human がうまく抑えたとき、境界仕事が正負どちらへ出るか

です。

同じ actuator を共有しているので、「どの制御器がより大きな入力を出せるか」ではなく、**同じ入力能力をどう使っているか**を比較できます。

ゲームの安定化判定も、元の絶対姿勢からの距離ではなく、現在の hand boundary で移動した基準形状からの flexible deformation を使います。照準のためにホース全体を意図的に傾けたこと自体を「不安定」とは数えません。

## 11. この補講から本編へ戻る

Side Lab X1 で得た感覚を、本編では次の順で言語化できます。

- [第03章](03_pid_feedback.md): 少数の誤差と速度を戻す P / PD
- [第04章](04_state_space.md): 多変数状態、固有値、可制御性
- [第05章](05_lqr.md): 状態と入力のトレードオフから $K$ を設計
- [第06章](06_zmp_support_polygon.md): 接触が作れる入力範囲
- [第07章](07_lipm_step_control.md): 不安定な重心運動と支持点・ステップ制御

さらに先では、

> LIPM / Capture Point → Preview / MPC → Centroidal Dynamics → Whole-Body QP

と進みます。

Flexible Hose Control は二足歩行そのものではありません。

しかし、**不安定モード、状態観測、可制御性、入力制約、フィードバック**を一度別の物理系で見てから戻ることで、二足歩行の式を「ロボット固有の暗記物」ではなく、制御問題の一例として読みやすくなります。
