H1-4Bで変わったこと

ホースを横変位 y(s) の小変形としてではなく、各segmentの有限角度から中心線を再構成します。segment長は一定なので、大きく回転しても人工的な伸びや「98°だから即モデル外」という扱いにはなりません。

破線はその流量・材質で解いた非線形静的平衡です。そこへ小さな摂動を一度だけ与え、内部流れとの連成だけでRMSが20 mmまたは初期値の3倍へ達した時刻を onset と表示します。継続的な見た目用正弦波はありません。

Fast 22 は CI で 10/12/16 segment と dt=0.001/0.002 の onset が約1.58 sで一致しています。

H1-5-0: 手元pulseは横位置と角度を prescribed boundary として運動方程式へ入れます。緑の矢印が必要な手元反力です。仕事率は P = F_h v_h + M_h ω_h、累積境界仕事はその時間積分で、正なら手からホースへエネルギーを入れ、負なら手がエネルギーを抜いています。

H1-5-1: Pointer dragは破線のtargetを動かします。実際の緑の手元境界はtargetへ瞬間移動せず、横速度・横加速度・角速度・角加速度の上限を持つアクチュエータを通って追従します。下の2グラフでactualとtargetの遅れを確認できます。

H1-5-2: ゲームではRMSと静的平衡からのtip角度誤差をtargetにします。failure envelopeを一定時間超えると即失敗、時間切れまで耐えてtarget内滞在率を満たせば成功です。scoreは追従品質から、過剰な境界仕事とactuator saturationを減点します。

H1-5-3: 3D Game は上の2D nonlinear rod stateを [x,y] → [X,Y,Zfixed] で3D空間へ写しています。ホース運動をrenderer側で作り直していないため、3D Game と2D Debugは同じ物理状態を見ています。

H1-5-4: Easy / Normal / Expert / Insane で流量・安定化target・照準半径・必要命中率・手元authorityが変わります。水の命中はノズル位置とphysics outlet rayから計算し、安定化と命中率の両方を満たしたときだけ成功です。

H1-5-4A: bullseyeは難易度ごとのphysics-time scheduleで移動します。Easyも2.5秒後には操作が必要になり、Normal / Expert / Insaneは無操作ではクリアできないことをCIで固定しています。InsaneはFast 22を保ったまま成功可能側へ緩和しています。

H1-6-0/1: Human / P / PD を切り替えられます。P/PDはrender差分ではなくrod角速度から解析的にtip速度を観測し、Humanと同じ速度・加速度制限つきhand actuatorを使います。

H1-6-2: LQRはnonlinear equilibriumまわりで、free rod angle/rateとhand actuator stateを含む1-step mapを数値線形化します。入力は従来と同じ [x_hand*, θ_hand*] で、LQRだけ強いactuatorを使うことはありません。初回選択時だけ線形化とDAREを計算し、そのscenarioではcacheします。

H1-6-3: moving bullseyeから共通のhand referenceを作り、P/PDはそのreference tipに対する局所誤差、State FB / LQRは u=u_ref-K(x-x_ref) で追従します。State FBは比較用の固定 0.55×K、LQRは 1.00×K です。run結果は同一difficultyの比較表へ蓄積します。

本命モデル: 8要素 Euler–Bernoulli FEM + internal-flow coupling + 曲がりシャワーヘッド境界。 現在の教育用モデルの臨界流量は 約14.23 L/min です。
H1-4A 監査結果: 高流量側では、曲がりヘッド反力による静的平衡そのものが small-deflection 線形梁の範囲外です。18 L/min では計算上の静的変位が 約1.08 m、回転が約98°になるため、高流量表示は instability mechanism の定性的な linear extrapolation として見てください。大振幅の実物再現は次の H1-4B nonlinear model で扱います。

Phase 1で見ているもの

縦方向はホースの基準軸、横方向が小変形横変位です。太線が実際のFEM状態、破線がその流量での静的平衡形状です。初期に8 mmスケールの滑らかな変位と小さなbroadband速度摂動を一度だけ与えます。連続的な見た目用正弦波や外力は加えていません。既定の再生速度は×4で、数十秒の物理時刻を短時間で監査できます。

低流量では摂動が減衰し、臨界付近では減衰が遅くなり、Flutterでは内部流れとの連成によって振幅が成長します。線形 small-deflection の妥当範囲を超えた場合は、描画を飽和させず停止して明示します。

このH1-4では手元境界は固定です。次のH1-5で、手元位置・角度をPointer操作して暴れるホースを人間が抑えるゲームへ進めます。
