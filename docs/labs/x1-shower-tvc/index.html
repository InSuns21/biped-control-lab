H1-4Bで変わったこと

ホースを横変位 y(s) の小変形としてではなく、各segmentの有限角度から中心線を再構成します。segment長は一定なので、大きく回転しても人工的な伸びや「98°だから即モデル外」という扱いにはなりません。

破線はその流量・材質で解いた非線形静的平衡です。そこへ小さな摂動を一度だけ与え、内部流れとの連成だけでRMSが20 mmまたは初期値の3倍へ達した時刻を onset と表示します。継続的な見た目用正弦波はありません。

Fast 22 は CI で 10/12/16 segment と dt=0.001/0.002 の onset が約1.58 sで一致しています。ただしパラメータは実物同定値ではなく、動画の「すぐ暴れる」時間スケールが非線形モデル内で成立可能かを見る感度ケースです。

本命モデル: 8要素 Euler–Bernoulli FEM + internal-flow coupling + 曲がりシャワーヘッド境界。 現在の教育用モデルの臨界流量は 約14.23 L/min です。
H1-4A 監査結果: 高流量側では、曲がりヘッド反力による静的平衡そのものが small-deflection 線形梁の範囲外です。18 L/min では計算上の静的変位が 約1.08 m、回転が約98°になるため、高流量表示は instability mechanism の定性的な linear extrapolation として見てください。大振幅の実物再現は次の H1-4B nonlinear model で扱います。

Phase 1で見ているもの

縦方向はホースの基準軸、横方向が小変形横変位です。太線が実際のFEM状態、破線がその流量での静的平衡形状です。初期に8 mmスケールの滑らかな変位と小さなbroadband速度摂動を一度だけ与えます。連続的な見た目用正弦波や外力は加えていません。既定の再生速度は×4で、数十秒の物理時刻を短時間で監査できます。

低流量では摂動が減衰し、臨界付近では減衰が遅くなり、Flutterでは内部流れとの連成によって振幅が成長します。線形 small-deflection の妥当範囲を超えた場合は、描画を飽和させず停止して明示します。

このH1-4では手元境界は固定です。次のH1-5で、手元位置・角度をPointer操作して暴れるホースを人間が抑えるゲームへ進めます。

比較モデル: Phase 0 は単一剛体＋復元重力＋減衰なので自然に安定しやすく、 flexible-hose flutter を含みません。
