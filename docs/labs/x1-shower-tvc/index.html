見方

薄い直立線が目標姿勢です。黄色の矢印はシャワーヘッドが受ける流水反力、水色の線はその反対向きへ出る水流、赤は重力、紫はジェットが作るトルクです。描画はX1-2のphysics stateを読むだけで、運動方程式はこのLab側に複製していません。ベクトル矢印の長さは見やすさのための表示スケールで、実寸ではありません。

最初はTVCを0°のまま観察し、傾きが重力で増えることを確認してください。その後 δx / δz を動かすと、作用線の偏向が姿勢回転へどう変換されるかを3Dで確認できます。指令は物理上限を超えて入力でき、適用値は |δ|≤25°、Q≤10 L/min に飽和します。
