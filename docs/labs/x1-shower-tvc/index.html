このモデルで何をしているか

手元の保持点が上、重心が下なので、重力そのものは姿勢を鉛直へ戻す復元力です。一方、シャワーヘッドの噴出口合力線はホース軸から少しずれており、下向きに水を出すと、その反力が回転モーメントを作ります。柔らかいホースを手で傾けると保持トルクが生じ、それを使って水流を真下へ保ちます。

水色が実際に出ていく水、黄色がヘッドへ返る反力です。紫は流水反力が作るトルク、緑は手で保持したホースが与えるトルクです。矢印長は可視化用スケールで実寸ではありません。

TVCはこのゲームの操作そのものではありません。 固定ノズルのシャワーヘッドを直接ジンバルしているわけではなく、「外力の作用線・方向と姿勢制御」という数理的な対応を後段でロケットTVCへ接続します。
