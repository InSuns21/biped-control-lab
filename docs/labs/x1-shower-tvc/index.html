Side Lab X1 — Flexible Hose Control

内部を水が流れる柔軟ホースが、低流量では減衰し、臨界付近では振れが長く残り、臨界超過では自励的に振幅を増やす様子を比較します。

Phase 1で見ているもの

縦方向はホースの基準軸、横方向が小変形横変位です。太線が実際のFEM状態、破線がその流量での静的平衡形状です。初期に8 mmの微小摂動だけを与え、見た目用の正弦波は加えていません。

低流量では摂動が減衰し、臨界付近では減衰が遅くなり、Flutterでは内部流れとの連成によって振幅が成長します。線形 small-deflection の妥当範囲を超えた場合は、描画を飽和させず停止して明示します。

このH1-4では手元境界は固定です。次のH1-5で、手元位置・角度をPointer操作して暴れるホースを人間が抑えるゲームへ進めます。
